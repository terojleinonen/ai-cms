# AI-Powered CMS Template

This repository is a starter template for an AI-powered CMS with:

- **Backend**: C# / ASP.NET Core Web API
- **Frontend**: Next.js (App Router) + TypeScript
- **Architecture**: Clean-ish separation (Domain, Application, Infrastructure, Api, Ai)
- **AI-ready**: Stub services and endpoints for text and image generation

## Structure

- `backend/` - ASP.NET Core solution with multiple projects
- `frontend/` - Next.js app for admin UI + public site
- `docker/` - Docker and docker-compose placeholders

This is a **template**: it compiles with minimal changes but leaves real business logic and AI integration for you to implement.
